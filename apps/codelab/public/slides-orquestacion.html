El mapa completo · parte 2

Con codigo: frameworks y runtime gestionado

Python / TS / Go / Java / Kotlin

ADK

El framework que ya usaste en las Demos 2 y 5: agentes secuenciales, paralelos o jerarquicos, con control total del loop de tool-calling.

Codigo a produccion

Agent Engine

Runtime gestionado dentro de la Gemini Enterprise Agent Platform: despliega y escala los agentes ADK que ya construiste, sin Dockerfile ni Cloud Run propio.

Estandar abierto

Protocolo A2A

Deja que agentes de equipos o frameworks distintos (ADK, LangGraph, etc.) se descubran y se hablen entre si con un contrato comun.

Regla practica: si tu equipo no programa, empieza en Gemini Enterprise o Conversational Agents. Si ya tienes agentes en codigo — como los de este proyecto —, ADK + Agent Engine es la ruta directa a produccion sin reescribir nada.
