Las dos piezas que hacen esto "agentico"

ADK y WebMCP en una frase

  • ADK (Agent Development Kit): framework oficial de Google para construir y orquestar agentes — SDK real de TypeScript.
  • WebMCP (document.modelContext): como una pagina web expone sus propias acciones como herramientas para un agente.
